# Нейросеть для улучшения качества фотографий лиц

## Описание проекта
Проект представляет собой систему глубокого обучения для улучшения качества портретных фотографий. Нейросеть обучается преобразовывать изображения низкого качества в изображения высокого качества с сохранением деталей и естественного вида лиц.
результаты обучения: training_results_improved\images\
примеры скринов работы бота: screens\
telegram: @dreamartistbalash_bot

## Технические детали

### Датасет

**Источник**: [CelebA Dataset](https://www.kaggle.com/datasets/jessicali9530/celeba-dataset)  
**Использовано**: 1000 фотографий (ограничение введено для экономии вычислительных ресурсов)  
**Размер изображений**: 178×218 пикселей  
**Формат**: RGB  

### Подготовка данных

Для создания пар обучения "низкое качество → высокое качество" использован скрипт `lquality.py`. Процесс искусственной деградации состоит из 6 последовательных этапов:

#### 1. Понижение разрешения с последующим увеличением
- **Операция**: Уменьшение до 50% от исходного размера, затем возврат к исходным размерам
- **Эффект**: Потеря высокочастотных деталей, пикселизация
- **Цель**: Имитация дешевых камер с низким разрешением

#### 2. Гауссово размытие (Gaussian Blur)
- **Параметры**: Ядро 5×5 пикселей, σ = 1.0
- **Эффект**: Дополнительное сглаживание, уменьшение резкости границ
- **Цель**: Имитация расфокусировки и движения камеры

#### 3. Добавление гауссова шума
- **Параметры**: Среднее μ = 0, стандартное отклонение σ = 10
- **Эффект**: "Зернистость", случайные цветовые отклонения
- **Цель**: Имитация высокого ISO и плохого освещения

#### 4. Артефакты сжатия JPEG
- **Параметры**: Качество сжатия 75%
- **Эффект**: Блочные артефакты, цветовые искажения, "муар"
- **Цель**: Имитация интернет-сжатия и низкокачественных форматов

#### 5. Уменьшение контраста
- **Параметры**: α = 0.9, β = 5 (формула: new_pixel = α × old_pixel + β)
- **Эффект**: "Выцветшее" изображение, уменьшенный динамический диапазон
- **Цель**: Имитация старых фотографий и плохой экспозиции

#### 6. Сохранение парных изображений
- **Структура**: 
  - Исходные изображения: `himage/photo_name.jpg`
  - Ухудшенные изображения: `limage/photo_name.jpg`
- **Формат сохранения**: JPEG с качеством 95% (для минимизации дополнительных артефактов, баланс между размером и рельной пользой)

### Результат подготовки

После обработки создаются парные наборы для обучения нейросети: Оригинал (himage/) → Ухудшенное (limage/)
Каждая пара используется для обучения модели преобразования изображений низкого качества в высокое качество.

### Архитектура сети
Модель основана на архитектуре остаточных нейросетей (ResNet) со следующими компонентами:

Входные данные:
Размер: 178×218×3 (высота × ширина × RGB каналы)
Формат: Тензор PyTorch [batch, channels, height, width]

**Основные слои:**
1. Входной сверточный слой (9×9 ядро)
2. 16 остаточных блоков (оптимизировано до 8 в финальной версии)
3. Промежуточные сверточные слои с нормализацией
4. Выходной сверточный слой

**Ключевые особенности:**
- Skip-connections для сохранения градиентов
- Batch Normalization для стабилизации обучения
- PReLU активационные функции
- Dropout слои для регуляризации (0.1)

### Процесс обучения

#### Этап 1: Начальное обучение (5 эпох), обучение прервано, в структуре приведено справочно, в дальнейшей работе не использовалась
- **Архитектура**: 16 остаточных блоков
- **Batch size**: 8
- **Learning rate**: 0.0001
- **Оптимизатор**: Adam
- **Устройство**: CPU
- **Метрика**: L1 Loss

#### Этап 2: Улучшенное обучение (30 эпох) - используется для чат-бота
- **Архитектура**: 8 остаточных блоков + Dropout
- **Регуляризация**: L2 weight decay (1e-5)
- **Планировщик**: ReduceLROnPlateau
- **Ранняя остановка**: Patience = 5 эпох
- **Лучшая модель**: 30-я эпоха, Val PSNR = 29.69 dB

### Ограничения и решения

**Ограничение: обучение на CPU**
- **Проблема**: Отсутствие GPU значительно замедляет процесс обучения
- **Решение**: Оптимизация архитектуры и гиперпараметров
  - Уменьшение количества остаточных блоков с 16 до 8
  - Уменьшение batch size до 8
  - Использование более простых операций свертки
  - Градиентный клиппинг для стабильности

**Ограничение: фиксированный размер изображения**
- **Проблема**: Модель требует вход 178×218 пикселей
- **Решение**: Предобработка изображений в боте с детекцией лиц и обрезкой

# Запуск проекта на Windows

## 1. Установка Python
- Установите Python 3.12 или новее с [официального сайта](https://www.python.org/downloads/)
- Убедитесь, что Python добавлен в PATH

## 2. Создание виртуального окружения
py -3.12 -m venv finalenv

## 3. Активировать окружение
finalenv\Scripts\activate

## 4. Обновить pip
python -m pip install --upgrade pip

## 5. Проверить версию Python
python --version  # Должен показать Python 3.12.x

## 6. Установить пакеты
pip install -r requirements.txt

## 7. Клонируйте проект
git clone ваш_репозиторий
cd dream-artist-bot

## 8. Установите зависимости
pip install -r requirements.txt

## 9. Создайте бота в @BotFather
- Получите токен

## 10. Создайте переменную окружени
TELEGRAM_FINAL_TOKEN="ваш_токен"

## 11.  Создайте папки
python -c "from utils import create_folders; create_folders()"

## 12. Простой запуск
python bot.py

## 13. Запуск с логированием
python bot.py 2>&1 | tee logs/bot.log

## 14.  Выйти
deactivate
