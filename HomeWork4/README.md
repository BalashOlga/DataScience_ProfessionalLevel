
# Чат-бот для новогодней тематики

## Описание проекта

Чат-бот, разработанный для помощи в подготовке к Новому году. Бот отвечает на вопросы, связанные с новогодними традициями, рецептами, подарками, развлечениями и другими праздничными темами.
Результат работы можно посмотреть: Telegram.docx

## Архитектура проекта

### Выбранный тип нейронной сети

Для реализации чат-бота использована **полносвязная нейронная сеть (Feedforward Neural Network)** с тремя линейными слоями:

- Входной слой: размерность соответствует размеру словаря
- Скрытый слой: 128 нейронов с функцией активации ReLU
- Выходной слой: количество классов (тегов интентов)

Архитектура сети реализована в классе `NeuralNet` в файле `model.py`.

## Реализованные функции

### 1. Система логирования

- **Логирование обучения**: запись процесса обучения модели с метриками
- **Логирование чата**: запись всех вопросов пользователей и ответов бота
- **Автоматическое создание лог-файлов** с датировкой
- **Консольный вывод** для мониторинга в реальном времени

### 2. Обработка естественного языка

- **Токенизация русскоязычного текста** - разбиение предложений на отдельные слова (токены)
- **Создание мешка слов (bag-of-words)** - метод представления текста в виде числового вектора, где каждый элемент показывает наличие или отсутствие слова в словаре
- **Нормализация текста** - приведение к нижнему регистру для унификации обработки

### 3. Контекстное взаимодействие

- Сохранение истории диалога
- Учет предыдущих сообщений для улучшения ответов
- Механизм уточняющих вопросов при низкой уверенности

### 4. Многоплатформенность

- **Консольная версия** (`chat.py`)
- **Telegram-бот** (`telegram_bot.py`)

## База знаний

Бот обучен на 14 категориях вопросов:

- Приветствие
- Праздничная кухня и рецепты
- Анекдоты и юмор
- Поздравления
- Пожелания
- Праздничные традиции
- Подарки
- Создание праздничного настроения
- Организация детского праздника
- Новогодние фильмы
- Планы на праздники
- Прощание
- Благодарность

## Установка и запуск

### 1. Установка зависимостей

```bash
install_chatbot.bat
```

### 2. Обучение модели

```bash
python train.py
```

### 3. Запуск чат-бота

```bash
python chat.py
```

## Telegram-версия

1. Получите токен бота у @BotFather
2. Замените BOT_TOKEN в файле telegram_bot.py
3. Запустите:

```bash
python telegram_bot.py
```

### 4. Результаты работы

### Производительность модели

- Размер словаря: ~250 уникальных слов
- Количество тегов: 14 категорий
- Точность классификации: высокая для четко сформулированных запросов
- Время отклика: менее 1 секунды

### 5. Логирование

Система создает два типа логов:

- training_YYYY-MM-DD.log - процесс обучения модели
- chat_YYYY-MM-DD.log - диалоги пользователей

## Особенности реализации

- **Адаптация под русский язык**: модифицированы функции обработки текста для работы с кириллицей
- **Градация уверенности**: разные стратегии ответа в зависимости от уровня уверенности модели
- **Расширяемость**: простая структура для добавления новых интентов
- **Обработка ошибок**: устойчивость к некорректным запросам
